## 使用规范

1. **新建方案**：在 `docs/plans/` 下创建 `phaseXX-description.md`，更新本索引
2. **方案完成**：将其移至 `docs/archive/`，更新本索引
3. **命名**：用 `phaseXX-description.md` 格式（如 `phase09-course-module.md`），不用无编号 slug
4. **归档文件只读**：历史方案仅作参考，不再修改
