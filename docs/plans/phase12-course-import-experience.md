# Phase 12：课程页与教务导入体验改进

> 状态：实施中。M1 加载状态、过期请求隔离与时间归一化已于 2026-09-09 合并；M2 四步向导待实施。

## 1. 当前问题与证据

| 问题 | 代码与截图证据 | 处理方向 |
|---|---|---|
| 加载、报错、空状态并存 | CourseView 的课程列表与 CourseSchedulePanel 的概览使用不同 store；列表失败后仍可显示空状态，概览仍可能等待 | 明确加载、成功为空、失败、旧数据刷新四种状态，分别显示 |
| 教务导入缺少链接入口 | CourseIntegrationsPanel 的 Web 分支仅生成书签代码，Android 分支才有打开教务按钮 | Web 显示可点击学校网址和“打开教务网站” |
| 点击预览像没反应 | onPreview 将预览放到父组件上方；错误 message 在 WebDAV、自动模式等内容之后 | 成功进入预览步骤；错误就在字段旁及底部操作栏上方 |
| 作息文本容易报错 | schoolImport.ts 严格要求 HH:mm；截图中的 8:00 不符合正则 | 时间选择器、结构化作息及输入归一化 |
| 视觉割裂 | 新模块以 course-settings 原生表单和描边按钮呈现，缺少主次操作层级 | 复用现有课程页、学期编辑 sheet 的样式与交互 |
| 工具挤占课程内容 | JSON、ICS、显示提醒、教务同步五个按钮直接常驻课程页 | 收拢入口，按导入、课表设置、数据管理分类 |

加载超时的线上根因尚未确定。后续须核对 Render 实际部署提交、健康接口、认证和课程请求，不能仅通过延长超时或换文案宣布修复。

## 2. 入口与信息架构

```text
课程表                         [导入] [+] [更多]
  学期选择
  下一节课程 / 今日课程
  课程列表

导入
  从教务系统导入
  从 ICS 文件导入
  从课表备份恢复（链接到设置的数据管理）

更多
  课表设置：外观、显示、提醒、免提醒日期、Android 上课模式
  学期与作息
  导出到日历（ICS，标明当前学期或全部）

设置 → 数据管理
  本地备份与恢复
  WebDAV 备份与恢复 → 课表备份
```

- 顶部导入图标与空状态按钮打开同一个导入选择器；空状态主按钮改为“导入课表”，不只指向 ICS。
- 保留手动创建课程和学期选择 pill，不改变现有主导航。
- WebDAV 从教务导入面板完整移出，使用设置页现有卡片布局。当前实现只备份课表，不得改名后暗示支持全应用备份，也不得与设置页既有全应用 JSON 格式混用。
- “自动节假日与上课模式”归入课表设置；Web 只展示可用的提醒项，Android 展示系统勿扰及其权限状态。

## 3. 教务导入：四步流程

### 第一步：选择学校

- 搜索后以学校列表卡片显示学校名、教务系统、适配状态；最近使用学校优先。
- 选中后显示可点击的教务网址、打开按钮；修改地址放在“地址不正确？”折叠区。
- 目录中有脚本仅代表“已提供适配”，不能标为“已验证可用”；兼容性以实际测试记录为准。
- 地址为空时显示“该学校暂未提供入口，请填写教务网址”；地址格式错误在字段旁提示。
- HTTP 学校入口保留轻量提示。不得将未经核实的默认学校地址用于其他学校。

### 第二步：获取课表

**Web 桌面端**：展示“打开教务网站”外链，在新标签页中由用户登录、选择学期并查看课表。随后使用现有书签工具导出教务结果，回到 SparkFlow 上传；提供简短图文步骤和文件拖放区。原始 JavaScript 仅在“手动安装导入工具”中展开。

**Web 移动端**：优先提供上传教务结果文件和 ICS 的可用路径；说明可在电脑完成书签导出后传入手机。不能把移动浏览器不可靠的书签执行作为唯一方案。

**Android 安装版**：保留现有 SchoolImport.open 登录与解析流程，增加“正在打开、等待登录、解析中、已读取”的反馈；插件不可用时提供文件导入。

打开链接不等于自动读取课表。普通网页无法直接读取另一个学校网站的登录页面；本期保留现有文件桥接，不承诺仅输入网址即可完成跨站自动抓取。

成功读取后显示“读取到 13 条排课”，不要直接等同于 13 门独立课程；按钮进入学期与作息配置。

### 第三步：确认学期与作息

- 先选择“使用已有学期”或“创建新学期”；新学期名称由学校和学年学期生成并可编辑。
- 优先使用导入的开始日期、总周数；缺少结束日期时按用户确认的周数生成建议，仍可修改。
- 明确“第一周周一”锚点并给出对应日期，避免开学日期不在周一导致误解。
- 作息来源优先级：导入结果 → 本人保存的该学校模板 → 手动配置/批量生成。未知学校不套用未确认模板。
- 已有学期使用不同作息时，不静默覆盖其历史课程时间；本次导入使用选定的作息，模板修改单独确认。

作息编辑区示例：

| 节次 | 开始 | 结束 |
|---|---|---|
| 第 1 节 | 08:00 ▾ | 08:45 ▾ |
| 第 2 节 | 08:55 ▾ | 09:40 ▾ |

- 使用平台适配的时间选择器，内部值统一为 HH:mm；粘贴文本时兼容 8:00、中文冒号及常见连接符，并显示转换后的结果。
- 默认只展示导入课程实际涉及的节次；支持添加、删除和复制上一节。缺失第 9–10 节时直接定位并提示相关课程。
- 提供“批量生成”：首节开始、每节时长、课间间隔、节数；上午/下午/晚间分段设置，大课间单独覆盖。生成后预览再应用，避免把午休按普通课间计算。
- “保存为学校作息”按账号和学校保存；支持模板名称，如夏季/冬季作息。首期明确为本机保存，跨设备同步另行扩展。
- 亚洲/上海时区作为说明小字“按北京时间排课”；从其他时区设备导入时仍按同一时区解释，展示转换规则。
- 校验结束早于开始、重复节次、时间重叠、缺失节次、无效日期和周次；错误紧贴对应字段，并滚动聚焦第一个错误。

### 第四步：预览与确认导入

- “查看导入预览”直接切换到预览页，不在原长页面的上方悄悄插入内容。
- 预览显示目标学期、独立课程数、排课条目数、实际生成的上课次数及被日期范围排除的条目。
- 以现有课程卡片显示课程名、教师、地点、周几、节次及时间、单双周/周次；支持返回上一步修正且保留内容。
- 识别重复排课和时间冲突，分别展示。首期提供“跳过重复（默认）/保留副本”，不默默覆盖原课程；覆盖更新作为后续能力。
- 底部固定“返回修改 / 确认导入”，使用用户操作语义“导入”，不再叫“恢复”。
- 提交期间锁定按钮；接口成功后显示成功页并切换到目标学期。刷新列表失败时保留导入成功结论，提供“刷新课表”，不引导重复提交。
- 网络中断时显示“提交结果待确认”，用请求标识查询结果后再允许重试；服务端幂等保证重复点击或重试不生成重复课程。

## 4. 与项目 UI 一致的表现

- 页面背景 #f4f4f6、白色卡片、主文字 #242424、淡紫 #b0a8db、浅绿 #cae393；延续现有低饱和配色，不另建一套视觉主题。
- 主操作使用黑色胶囊按钮，导入入口使用淡紫色强调；次操作用浅灰底，危险操作独立确认。
- Lucide 图标、圆角输入块和现有排版层级。字段标签置于输入框上方，避免窄屏左右挤压。
- 移动端导入向导使用覆盖底部导航的全屏 sheet；桌面使用居中限宽面板。复用 CourseView 学期 sheet 的安全区与过渡模式，不直接套用任务编辑专属的多层旋转卡片。
- 固定头部显示标题/步骤/关闭，正文独立滚动，底部操作区计入 safe-area；软键盘弹出时当前字段和错误仍可见。
- 退出未完成流程时保留本次会话草稿；从教务标签页返回后仍处于获取课表步骤。
- 加载、按钮禁用原因、解析成功、错误使用同一套状态组件；焦点管理、键盘返回、屏幕阅读器状态通知纳入验收。

## 5. 稳定性与实现边界

### P0：先消除操作中断

1. 核验前端生产 alias 和 Render 的实际运行提交；检查 /api/health、认证、课程列表、课表概览接口的响应与日志。
2. 课程页统一状态契约，协调列表与概览请求；失败不显示“还没有课程”，旧数据刷新失败保留旧数据和提示。
3. 请求统一超时/取消，账号和学期切换时隔离过期响应；仅对可安全重试的查询做有上限的退避。
4. 为 Web 补齐学校外链、预览切换和就地错误；解析器接受合理时间格式。

### P1：重组界面与导入闭环

1. 将 CourseIntegrationsPanel 拆为教务向导、WebDAV 设置卡片、上课模式设置。
2. 增加结构化作息编辑器、模板和分段生成器；替换用户必须编写文本的路径。
3. 复用现有适配目录、解析 bridge 和 SchoolImport 原生插件；不在本期重写学校解析脚本。
4. 将 schoolBackup 的解析/归一化、校验、预览转换拆开；错误带字段或课程位置，保留旧 JSON 输入兼容。
5. 现有 importScheduleBackup 默认新增副本；新增教务导入用例须明确目标学期、去重规则和幂等标识，在后端验证且事务提交。不得只改前端按钮文字就声称支持合并或去重。

### P2：模板与体验增强

补充经过核验的学校作息模板、适配更新时间、导入历史及失败诊断导出。模板跨设备同步和直接更新既有排课独立设计，不阻塞首期。

## 6. 验收清单

- 360px 窄屏至桌面宽屏无横向溢出，键盘和底部导航不遮挡确认操作。
- 教务导入选择学校后能看到并打开网址；无入口、适配脚本失败、文件为空/错误均有可操作提示。
- 8:00 与 08:00 归一化结果相同；缺失节次、跨段午休、单双周、跨设备时区、学期日期裁剪有测试。
- 从接收文件到预览不依赖课程列表接口；服务不可用时仍可整理和预览，提交前明确说明不能写入。
- 点击预览后立即进入新步骤，错误不用滚动到长页面末尾才能找到。
- WebDAV 仅出现在设置的数据管理中，仍保留现有 ETag 并发保护，不能把课表备份当作完整应用备份。
- 重复提交、断网后重试不重复建课；成功后选中正确学期并显示结果。
- 浏览器、Android 各完成一条真实导入路径；线上健康、认证和课程接口验证后才标记发布完成。
