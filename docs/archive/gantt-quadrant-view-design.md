# 甘特图与四象限视图设计

## 结论

不增加底部导航入口。将两种新视图放进现有信息架构：

- `待办`：`列表 / 四象限`
- `时间轴`：`日程 / 甘特`

这样既能复用现有任务详情、筛选和编辑能力，也不会让移动端底栏继续膨胀。

## 四象限

### 分类规则（第一阶段无需改数据库）

| 象限 | 重要 | 紧急 | 现有字段映射 |
| --- | --- | --- | --- |
| 立即处理 | 是 | 是 | `priority = High Priority`，且已逾期或 72 小时内截止 |
| 计划推进 | 是 | 否 | `priority = High Priority`，且截止时间晚于 72 小时或未设置 |
| 尽快完成 | 否 | 是 | 非高优先级，且已逾期或 72 小时内截止 |
| 有空再做 | 否 | 否 | 非高优先级，且截止时间晚于 72 小时或未设置 |

已完成和已取消任务不进入矩阵。72 小时阈值后续可在设置中调整。

### 移动端布局

- 默认一次显示一个象限，用顶部 2×2 微缩导航切换，避免四格同时挤压卡片。
- 象限标题固定显示数量和含义，例如“立即处理 · 3”。
- 任务卡只显示标题、截止时间、项目色和完成按钮；点击进入现有任务详情。
- 支持拖到其他象限。改变“重要”会更新优先级；拖入“紧急”但没有截止时间时，先弹出截止日期选择，不能静默猜日期。

### 桌面布局

宽度大于 768px 时显示标准 2×2 矩阵。各象限独立滚动，保留拖放和键盘操作。

## 甘特图

### 时间模型

- 有 `scheduledStart` 和 `scheduledEnd`：显示为可拖动、可缩放的任务条。
- 只有 `scheduledStart`：用 `estimatedMinutes` 或 `duration` 推导结束时间。
- 只有 `dueDate`：显示为菱形里程碑，不伪造开始时间。
- 完全未排期：进入“待排期”抽屉，可拖入时间网格。
- 课程、会议和外部日历：显示为带纹理的只读背景条，避免用户误以为可以移动。

### 视图结构

- 顶部范围切换：`本周 / 两周 / 本月`，默认两周。
- 左侧固定任务名，右侧横向时间网格；移动端两者保持同步滚动。
- 默认按项目分组，没有项目时按任务分区 `section` 分组。
- 今天用高对比竖线标记；周末只降低背景对比，不隐藏。
- 拖动任务条修改开始和结束；拖动两端修改时长；锁定任务不可移动。
- 冲突时显示红色轮廓并给出原因，松手后回到原位，不自动覆盖课程或锁定事项。

## 统一视觉与交互

- 页面背景使用 `--sf-surface`，输入区使用 `--sf-bg`，主按钮使用 `--sf-text-primary`，按钮文字使用 `--sf-surface`。
- 主按钮必须有可见文字，图标只作辅助，不能单独承担含义。
- 弹层统一支持：显式关闭按钮、点击遮罩、Esc、安卓返回键、滚动锁和焦点管理。
- 全屏复杂流程（AI 安排、甘特编辑）使用左上“关闭”胶囊；轻量编辑继续使用底部 Sheet。

## 实施顺序

1. 修复弹层生命周期和按钮对比度，统一 AI 安排页视觉。
2. 上线只读四象限与甘特图，验证分类规则和信息密度。
3. 加入拖放、调整时长、冲突检测和键盘操作。
4. 根据使用反馈决定是否增加独立的 `importance` 字段；在此之前不做数据库迁移。

## 验收指标

- 360px 宽屏幕不出现页面级横向溢出；甘特网格仅在自身区域横向滚动。
- 任一弹层都能通过界面按钮、Esc 和安卓返回键关闭。
- 四象限中的任务总数与同一筛选条件下的待办任务数一致。
- 甘特条拖动后保存的时间与网格刻度误差不超过 15 分钟。
- 锁定任务、课程和外部事件永远不会被拖动修改。
